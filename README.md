# 基本的なルール（カラーコード版 / マスターマインド形式）

## 1. 役割分担

- コードメーカー：秘密のコード（例：赤・青・緑・黄など4色のピンやカラー）を隠し持ちます。
- コードブレーカー：色や数字を推測してコードを配置し、正解を暴きます。

## 2. 推測とフィードバック

- コードブレーカーが自分の推理を置くと、コードメーカーがヒント（フィードバック）を返します：
  - 黒いピン（ヒット）：色も場所（位置）も合っている。
  - 白いピン（ブロー）：使われている色（または数字）は合っているが、位置が違う。
- ヒントを手がかりに、制限回数（一般的には10回〜12回程度）以内に完全一致を目指します。
